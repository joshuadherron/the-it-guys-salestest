# Managed IT quote commercial rules — Pricing Sheet v20

This file documents the approved sales pricing constraints. It does not replace the live pricing configuration.

- Managed IT: $125 per user per month; $375 monthly minimum on Managed IT user fees alone (3-user equivalent).
- Monitoring-Only: $45 per device per month, $225 minimum combined with Managed Server Add-Ons. Monitoring-Only is out of scope for COM-PRP document fill.
- Managed Server Add-On: $75 per server per month, in addition to user/device fees.
- Shared or additional managed business devices beyond 3 assigned devices/user: $15/device/month.
- Microsoft 365 backup: $5 per covered user/month.
- On-site block: $115/hour/month, prepaid; no rollover; overage $125/hour. As-needed subscribed on-site: $125/hour.
- Onboarding: owner-selected $300–$750 guided range; not a formula.
- System backup: owner-priced per protected system; do not invent flat fees.
- Volume discounts: discretionary owner-approved; not automatic.
- 12-month initial term, auto-renewal for 12 months, 30-day nonrenewal notice; 4% annual recurring adjustment on renewal with 45-day notice unless signed schedule differs.
- Hardware separately priced at cost +20% markup; deployment labor separate.
- Client-specific terms and scope narrative must be owner-entered, never invented.
- All quote figures must come from the approved quote calculation, not hard-coded rates in a field builder.
